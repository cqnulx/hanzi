# Hanzi 中文智能伴学网页

面向多种母语用户的中文学习网页，集成模型导学、跨会话学习记忆、动态学习画像、学习计划、视频课程、发音练习、交互式写作和学习反馈纠偏。

## 启动

需要 Node.js 20 或更新版本，无需安装第三方依赖。

1. 确认项目目录内有 `.env`，按 `.env.example` 填入 `DEEPSEEK_API_KEY`。密钥仅由后端读取，不会下发浏览器。
2. 在项目目录运行 `node server.mjs`。
3. 在浏览器打开 <http://127.0.0.1:4173>。

学习记录保存在 `data/`。分享代码时排除 `.env` 和 `data/`。模型请求仅发往 DeepSeek 官方 API；网络、余额或授权问题会明确显示。

## 功能与边界

- 网页支持中文、英文、西班牙语、法语、德语、日语和韩语，即时切换界面并保存偏好。课程说明、习题、学习计划、对话和批改使用所选辅助语言；中文例句、拼音和学习者原文保持原样，短句、词汇及视频字幕显示相应译文。学习目标仍是中文，英文参考译文单独保留。导学结合学习目标、相关历史记忆、练习证据和既往反馈。
- 切换语言时，旧课程的标题、简介以及调整决定的理由和难度说明也会按需翻译并保存；准备中显示当前语言的提示，不混用旧说明。学习者输入的原始请求保持原文。翻译只改变文案，不重新决定课程主题或难度。
- 产品界面统一使用“智能伴学助手”等中性名称，不展示模型厂商或 AI 标识；后台仍通过已配置的模型完成课程、习题、计划与教学反馈。
- 使用重庆师范大学校徽及电脑横屏布局。右侧工作区文字统一黑色，中文使用本机宋体、英文和拼音使用微软雅黑，保留放大的字号；教学动画采用相同字体与黑色文字。
- 记忆区分具体学习事件与提炼的学习特征，保存来源、时间、置信度及更新关系；旧记录可被替代或归档。
- 学习完成只记为练习证据，不直接认证知识掌握或 HSK 水平。反馈归因是待验证的判断。
- DeepSeek 参与每个教学步骤：生成完整个性化课程与视频脚本、生成新习题、逐题解释和学习诊断、选择学习计划的任务/顺序/时长、口语转写后的教学反馈、写作修改、画像解读、学习完成反思、记忆理解与反馈归因。界面导航、播放、数据管理等执行动作不额外调用模型。
- 课程和习题按浏览器档案、课程及语言保存模型生成缓存。练习每次由模型生成一道题，提交后由后端核对答案，再由模型批改；下一题结合实际对错、错选项和薄弱点选择新情境，答对后举一反三，答错后换例子巩固。页面保留已答题回顾。未答题会续用，避免刷新或双击跳题；新题与近期题干去重，重复时向模型反馈并重试一次，仍重复则提示重试并保留原记录。习题答案保存在后端私有会话数据中，生成题目、学习状态及导出接口均不泄露答案。模型失败会显示错误，不改用静态题或本地计划冒充模型结果。
- 发音示范使用浏览器语音合成，语音录入依赖浏览器 Web Speech 能力。可用中文声音、支持情况和权限因浏览器而异；部分语音识别服务需要网络。识别后的文字匹配率不是发音、声调或口音评分。
- 口语页提供“中文自由朗读”，无需先生成课程。可输入任意汉字、词语或句子，选择慢速、自然或流畅朗读，并停止播放或清空文字。设备需安装普通话语音；多音字及生僻字的读法由所选语音引擎决定。
- 视频根据模型生成的课程脚本，在浏览器内制作带简体中文、拼音和所选辅助语言字幕的本地动画 WebM，不依赖外部视频站点。动画本身无声，普通话示范由旁边的发音按钮提供；模型脚本完成后，视频制作约需十余秒。生成与播放支持取决于浏览器的 Canvas、MediaRecorder 和 WebM 能力。
- 个人数据可导出、删除单条记忆或清空全部学习数据。不同浏览器通过独立 HttpOnly cookie 区分学习档案。

电脑后端可通过 `gateway.mjs` 与 HTTPS 通道连接 GitHub 网页，具体步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。用户选择不设访问口令和请求限额；浏览器通过独立会话隔离学习记录，密钥和文件保留在本机。电脑和通道需持续在线。

所有访问者的请求可在本机 <http://127.0.0.1:4173/monitor> 集中查看输入、返回和失败原因，使用说明见 [MONITORING.md](MONITORING.md)。

## 调整后新增相关课程

在学习路径中填写具体调整，例如“我想学习中国的城市”，再点击调整。伴学助手先结合已有课程、填写的水平、实际练习证据和反馈判断：仅调整练习安排、沿用一门已有课程，或在确实缺少相关主题且适合当前学习准备度时新增课程。页面明确显示决定、理由、本次练习难度及依据；该难度是教学建议，不是测定或认证的 HSK 水平。

确需新增时，课程进入课程、口语和写作的下拉栏并自动选中，页面显示显著的新课程卡及学习入口。多语言标题和简介随当前浏览器学习档案保存，刷新仍可选择。旧定制课首次切换到尚未准备的语言时，页面自动翻译目录和调整说明，显示准备进度后保存相应译文。沿用已有课程或仅调整安排时，不会额外创建课程；实际课程及习题缓存会失效，之后按新的难度和重点重新生成，同时保留写作草稿。

调整判断、新课程目录、实际课程内容、视频脚本、习题及反馈均由后台模型按需生成。判断和计划验证全部成功后才保存；计划格式或约束不合格时，向模型反馈问题并修正一次，仍不合格则保留原计划并提示重试，不用本地计划替代。新课只属于当前学习会话，其他浏览器不会混入这门课。清空学习档案或删除相关学习记忆时，派生课程会随派生内容重置。

## 按答题正确率调整下一次学习难度

提交习题后，服务器核对答案，并将近期独立首答的正确率、题量、当前练习难度和错误情况交给伴学助手。证据窗口累计最近约二十题、最多二十套作答；旧版每套四题时仍相当于最近五套，单题练习也能累积足够证据。助手在本次批改中决定下一次学习是提高一级、保持还是降低一级，并给出理由及练习重点。页面同时显示本题成绩、近期正确率及下一次难度；课程、习题、写作指导和新学习计划均使用这个建议，旧内容缓存不会冒充调整后的新内容。

为避免少量题目导致难度跳动，至少在当前难度完成两次独立作答、八题，且近期和当前难度的正确率均达到 85%，下一次提高一级；当前难度至少两次独立作答、八题，且近期和当前难度的正确率均不超过 50%，下一次降低一级。只有一次低分时，助手可选择先巩固或降低一级。每次最多变化一级，限定在 HSK 1–6 的教学难度范围内。数量及正确率约束保证持续证据能触发调整，模型据此生成具体难度决定、理由和教学策略；它不是 HSK 水平认证，也不代表已经掌握未练习的主题。之后明确提出的计划难度要求可以覆盖旧答题建议，新答题证据又会用于后续判断。

同一套题重复提交、修改答案后再提交或切换界面语言，都不会再计为独立成绩或反复升降难度。反馈生成或难度决定校验失败时，保留之前的记录和难度，提示重新提交；不会以猜测的结果替代。数据按学习会话保存，其他访问者不会影响你的难度。

## 师小噜数字角色

页面右下角的师小噜使用用户提供的角色图，并加入重庆师范大学校徽与姓名胸牌、黑色博士帽和金色流苏，点击可打开独立导览对话框。可介绍当前区域、逐步参观六个学习模块，也可输入问题或使用浏览器语音转写。导览和互动均由电脑后端调用模型生成，基于实际功能清单、当前区域及学习记录回答；对话与原课程聊天分开保存，动作只能打开已有学习页面。切换语言后界面、回答和朗读语言保持一致。

博士帽已放大并上移，橘子完整露出。可直接拖动角色调整位置，位置仅保存在当前浏览器；移动到屏幕边缘时，对话框会选择可见位置打开，不改变正在进行的学习任务。

朗读支持开关、重播和停止，播放时显示角色动画。参考音色由本机 Qwen3-TTS 0.6B Base 根据用户提供的录音生成，输出默认降低一个半音并保持时长。先生成短句开始播放，并在播放时准备下一段，完整文字保留在对话框中；停止、切页或切换语言后不会继续播放旧内容。服务提前预热语音生成和降调运算，并缓存相同文字与语言的音频，减少首次朗读和重播等待。使用合成语音，不是原录音回放，也不保证完全复现原声。文字回答仍由现有教学模型生成。语音暂不可用时保留文字并提示，可主动选择设备卡通音色；不会静默替换。麦克风仅在用户点击后启动，不支持时仍可文字互动。

语音首次安装使用 `scripts/setup-lulu-voice.ps1`，指定原始音频和 Python 路径；需要 NVIDIA CUDA 显卡及约 6 GB 下载空间。录音片段、参考转写、模型和独立 Python 环境仅存放在 Git 忽略的 `runtime/lulu-voice/`，不发布到网页或仓库。语音服务由 `scripts/lulu-voice-service.py` 监听本机 4187 端口；网页通过电脑后端的 `/api/lulu/voice` 获取当前学习会话中已生成回答的音频。监测记录保留对应文字和音频长度，不保存音频字节。安装完成后，电脑后端启动脚本会一并管理语音服务。

## 算法来源

`algorithms.mjs` 是公开算法的无依赖原创实现，借鉴开源项目与公开文献的思路，没有复制或打包第三方项目代码：

- 记忆检索使用 BM25，结合时间衰减、置信度和检索次数。参考 [rank_bm25](https://github.com/dorianbrown/rank_bm25)（Apache-2.0）及 Robertson 与 Zaragoza 的 BM25 文献。
- 知识状态估计使用 Bayesian Knowledge Tracing（BKT）。参考 [pyBKT](https://github.com/CAHLR/pyBKT)（MIT）及 Corbett 与 Anderson 的 BKT 方法。默认参数未经真实学习数据校准，结果仅为暂定估计；同一后端签发题目的重复作答不会被计作独立新证据。
- 复习间隔采用 [SM-2 公开算法](https://super-memory.com/english/ol/sm2.htm)。先修关系图、BKT 与到期复习向 DeepSeek 提供证据建议；模型实际选择任务、顺序、难度和时长，后端只验证课程存在、先修顺序与每日时间预算。模型不可用或输出不合格时明确报错，不自动替换成算法计划。旧版算法计划不会作为新的模型计划显示。

运行 `node --test test/*.test.mjs`。覆盖数据隔离、密钥保护、输入验证、各教学环节模型调用、多语言课程缓存、所选语言译文、私有答案隔离、批改证据去重、无模型时错误、完整模型计划约束、七语言文案与占位符一致性及删除行为。无依赖安装和编译步骤。
