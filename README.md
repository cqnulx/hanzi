# Hanzi 中文智能伴学网页

面向英语用户的本地中文学习网页，集成 DeepSeek 导学、跨会话学习记忆、动态学习画像、学习计划、视频课程、发音练习、交互式写作和学习反馈纠偏。

## 启动

需要 Node.js 20 或更新版本，无需安装第三方依赖。

1. 确认项目目录内有 `.env`，按 `.env.example` 填入 `DEEPSEEK_API_KEY`。密钥仅由后端读取，不会下发浏览器。
2. 在项目目录运行 `node server.mjs`。
3. 在浏览器打开 <http://127.0.0.1:4173>。

学习记录保存在 `data/`。分享代码时排除 `.env` 和 `data/`。模型请求仅发往 DeepSeek 官方 API；网络、余额或授权问题会明确显示。

## 功能与边界

- 网页支持中英文即时切换并保存偏好；以简体中文、拼音和英文参考译文进行中文教学。导学结合学习目标、相关历史记忆、练习证据和既往反馈。
- 产品界面统一使用“智能伴学助手”等中性名称，不展示模型厂商或 AI 标识；后台仍通过已配置的模型完成课程、习题、计划与教学反馈。
- 使用重庆师范大学校徽及电脑横屏布局。右侧工作区文字统一黑色，中文使用本机宋体、英文和拼音使用微软雅黑，保留放大的字号；教学动画采用相同字体与黑色文字。
- 记忆区分具体学习事件与提炼的学习特征，保存来源、时间、置信度及更新关系；旧记录可被替代或归档。
- 学习完成只记为练习证据，不直接认证知识掌握或 HSK 水平。反馈归因是待验证的判断。
- DeepSeek 参与每个教学步骤：生成完整个性化课程与视频脚本、生成新习题、逐题解释和学习诊断、选择学习计划的任务/顺序/时长、口语转写后的教学反馈、写作修改、画像解读、学习完成反思、记忆理解与反馈归因。界面导航、播放、数据管理等执行动作不额外调用模型。
- 课程和习题按浏览器档案、课程及语言保存模型生成缓存；点击重新生成会调用模型创建新内容。习题答案保存在后端私有会话数据中，生成题目、学习状态及导出接口均不泄露答案；提交后由后端按答案核对，再由模型生成逐题解释和下一步建议。模型失败会显示错误，不改用静态题或本地计划冒充模型结果。
- 发音示范使用浏览器语音合成，语音录入依赖浏览器 Web Speech 能力。可用中文声音、支持情况和权限因浏览器而异；部分语音识别服务需要网络。识别后的文字匹配率不是发音、声调或口音评分。
- 口语页提供“中文自由朗读”，无需先生成课程。可输入任意汉字、词语或句子，选择慢速、自然或流畅朗读，并停止播放或清空文字。设备需安装普通话语音；多音字及生僻字的读法由所选语音引擎决定。
- 视频根据 DeepSeek 生成的课程脚本，在浏览器内制作带简体中文、拼音和英文字幕的本地动画 WebM，不依赖外部视频站点。动画本身无声，普通话示范由旁边的发音按钮提供；模型脚本完成后，视频制作约需十余秒。生成与播放支持取决于浏览器的 Canvas、MediaRecorder 和 WebM 能力。
- 个人数据可导出、删除单条记忆或清空全部学习数据。不同浏览器通过独立 HttpOnly cookie 区分学习档案。

电脑后端可通过 `gateway.mjs` 与 HTTPS 通道连接 GitHub 网页，具体步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。用户选择不设访问口令和请求限额；浏览器通过独立会话隔离学习记录，密钥和文件保留在本机。电脑和通道需持续在线。

所有访问者的请求可在本机 <http://127.0.0.1:4173/monitor> 集中查看输入、返回和失败原因，使用说明见 [MONITORING.md](MONITORING.md)。

## 调整后新增相关课程

在学习路径中填写具体调整，例如“我想学习中国的城市”，再点击调整。伴学助手先结合已有课程、填写的水平、实际练习证据和反馈判断：仅调整练习安排、沿用一门已有课程，或在确实缺少相关主题且适合当前学习准备度时新增课程。页面明确显示决定、理由、本次练习难度及依据；该难度是教学建议，不是测定或认证的 HSK 水平。

确需新增时，课程进入课程、口语和写作的下拉栏并自动选中，页面显示显著的新课程卡及学习入口。双语标题和简介随当前浏览器学习档案保存，刷新仍可选择。沿用已有课程或仅调整安排时，不会额外创建课程；实际课程及习题缓存会失效，之后按新的难度和重点重新生成，同时保留写作草稿。

调整判断、新课程目录、实际课程内容、视频脚本、习题及反馈均由后台模型按需生成。判断和计划验证全部成功后才保存；计划格式或约束不合格时，向模型反馈问题并修正一次，仍不合格则保留原计划并提示重试，不用本地计划替代。新课只属于当前学习会话，其他浏览器不会混入这门课。清空学习档案或删除相关学习记忆时，派生课程会随派生内容重置。

## 算法来源

`algorithms.mjs` 是公开算法的无依赖原创实现，借鉴开源项目与公开文献的思路，没有复制或打包第三方项目代码：

- 记忆检索使用 BM25，结合时间衰减、置信度和检索次数。参考 [rank_bm25](https://github.com/dorianbrown/rank_bm25)（Apache-2.0）及 Robertson 与 Zaragoza 的 BM25 文献。
- 知识状态估计使用 Bayesian Knowledge Tracing（BKT）。参考 [pyBKT](https://github.com/CAHLR/pyBKT)（MIT）及 Corbett 与 Anderson 的 BKT 方法。默认参数未经真实学习数据校准，结果仅为暂定估计；同一后端签发题目的重复作答不会被计作独立新证据。
- 复习间隔采用 [SM-2 公开算法](https://super-memory.com/english/ol/sm2.htm)。先修关系图、BKT 与到期复习向 DeepSeek 提供证据建议；模型实际选择任务、顺序、难度和时长，后端只验证课程存在、先修顺序与每日时间预算。模型不可用或输出不合格时明确报错，不自动替换成算法计划。旧版算法计划不会作为新的模型计划显示。

## 验证

运行 `node --test test/*.test.mjs`。覆盖数据隔离、密钥保护、输入验证、各教学环节模型调用、课程缓存、私有答案隔离、批改证据去重、无模型时错误、完整模型计划约束、中英文一致性及删除行为。无依赖安装和编译步骤。
